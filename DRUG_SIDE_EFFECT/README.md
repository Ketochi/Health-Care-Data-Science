# Health-Care-Data-Science

📌 Health Care Datascience
This repository showcases my applied projects at the intersection of healthcare, data science, and machine learning. It contains end‑to‑end workflows for cleaning, analyzing, and modeling complex medical datasets, with a focus on drug safety, patient outcomes, and predictive analytics.

🔬 Key Features
Data Engineering: Robust preprocessing pipelines for clinical and pharmacovigilance data (FAERS, patient surveys, etc.), including handling missing values, parsing nested lists, and building structured features.

Machine Learning Models:

Multilabel classification for predicting drug side effects.

Logistic regression, One‑Vs‑Rest classifiers, and scalable approaches with SGDClassifier.

Deep learning models in PyTorch for multilabel prediction with embeddings.

Natural Language Processing: Sentence embeddings (SentenceTransformers, BERT) to transform medical text (drug names, indications, reactions) into meaningful numerical representations.

Memory & Storage Optimization: Techniques such as sparse label matrices, compressed caching of embeddings, dimensionality reduction (PCA/SVD), and efficient incremental training.

Interactive Applications: A Tkinter‑based GUI for patient survey collection, demonstrating how data science can be integrated into user‑friendly healthcare tools.

🎯 Purpose
This repository reflects my ability to:

Translate healthcare challenges into data science solutions.

Build scalable, efficient pipelines for large medical datasets.

Apply machine learning and deep learning to improve understanding of patient safety and treatment outcomes.

🌍 Impact
By combining clinical knowledge with advanced analytics, the projects here illustrate how data science can support evidence‑based healthcare decisions, improve patient monitoring, and contribute to safer, more effective treatments.
